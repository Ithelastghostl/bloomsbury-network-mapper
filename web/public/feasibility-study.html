Wealth Band Algorithm

Composite score from observable signals (no LLM needed):

SignalWeightHow Measured
Number of active directorships15%Companies House officer appointments (active only)
PSC significant control20%Shareholding bands (25-50%, 50-75%, 75%+) across all controlled companies
Company types held15%Fund management (SIC 663), property (SIC 681), personal investment vehicles
Total political donations15%Sum of Electoral Commission reported donations
Charity income governed15%Total income of charities where individual is trustee
Foundation/trust involvement10%Count of charitable trusts/foundations as director or trustee
Property vehicle count10%Number of property-holding LLPs/companies as PSC

Band thresholds: Score 0–0.25 = Unknown/Low, 0.25–0.45 = £1M–5M, 0.45–0.65 = £5M–25M, 0.65–0.80 = £25M–100M, 0.80+ = £100M+

Strengths

  • 100% free — zero API costs
  • Government-authoritative data
  • Deterministic, reproducible scores
  • Full audit trail (every signal traced to source)
  • Fast: ~2 seconds per person
  • All 4 APIs confirmed working today
  • No rate limit issues at 350 seeds

Limitations

  • Cannot detect non-public wealth (private investments, offshore)
  • Name matching across sources needs entity resolution
  • No narrative/biographical context
  • Property values not in bulk data (£3/title individually)
  • Electoral Commission only covers political donations, not charity giving amounts directly

Verdict: Build All Three as a Unified Cascade

Maximum Effectiveness — Every Seed Gets All Three Layers

No gating, no conditional logic, no shortcuts. Every individual passes through A → B → C in sequence. Each layer builds on what the previous one discovered. The agentic layer (C) receives the structured data from A and the web research from B as context — making its own research targeted rather than exploratory.

The cascade creates a compounding accuracy effect: Strategy A provides the authoritative skeleton (directorships, donations, trusteeships). Strategy B fills narrative gaps and finds signals outside government registries. Strategy C's agents cross-verify everything, resolve conflicts, discover second-order connections, and produce the final wealth band with multi-source convergence.

Why the Cascade Beats Running Strategies Independently

Without Cascade (independent runs)With Cascade (layered)
Strategy C agents waste time discovering things A already has from authoritative sources (e.g., re-searching Companies House via web) Agents receive A's structured data as ground truth — they start from facts, not from scratch
B's LLM may hallucinate a directorship that A could have confirmed/denied from Companies House B's LLM is prompted with A's data — it knows which directorships are confirmed and only searches for what's missing
C's Wealth Agent guesses net worth from web articles alone C's Wealth Agent has A's PSC shareholdings + B's Rich List mention + its own analysis = convergent estimate
Conflicting data across strategies is unresolved C's agents explicitly resolve conflicts: "CH says resigned 2019, news says still involved" → investigate
Each strategy produces a separate score — unclear which to trust Single converged score with confidence level and evidence chain from all three layers
